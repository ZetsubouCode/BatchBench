# Jio7 classified Danbooru tags snapshot

Source: `Jio7/danbooru-tags-classified` on Hugging Face.

The upstream dataset metadata identifies the dataset license as MIT. This
snapshot is bundled as replaceable application classification data and is not
modified in place at runtime.

Snapshot contents used by BatchBench: `action`, `attire`, `count`,
`expression`, `feature`, `meme`, `meta`, `object`, `other`, `setting`, and
`requiring.txt`. The supplied development snapshot did not contain
`style.csv`; the loader reports missing categories without disabling manual
tagging.
