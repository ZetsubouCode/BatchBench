Webtoon Splitter

Stacks pages vertically (no gap), then slices wherever a horizontal selected-color band is detected. Works per chapter folder or across numbered subfolders.
Outputs: <chapter>_001.png, _002.png, ...
Folders & Input
If subfolders exist (Chapter 1, 2, etc.), each is processed separately.
Defaults to everything; narrow it if noise files exist.
Natural name order sorts 2.png before 10.png.
Gap is forced to 0; background is white.
Stripe detection
Examples: #FFFFFF or #FFFFFF, #000000.
Drop to 95–96% if gutters are noisy.
